## P2-2：SQL authority、cache owner 與控制通道

新增 ReActDataStoreV403、SharedCacheFodexFunV100、ParticipantOperationsFodexFunV405、ReActLoopHandlerV405、ReActTraceV302，舊版來源保留。另新增 NativeCommandFodexFunV100，以既有 Proc Supervisor 1.572.12 執行有限時、有限輸出的管理命令；非同步 ROP helper 放回既有 FodexFunBinding。

- cache 的 KV／journal 同一 transaction；兩側任一失敗全部 rollback。operationId 重試回原收據，不同 payload 拒絕。SQL 成功後才換 graph。

- 普通 loop 代理送件後即釋放 mailbox；SQL trigger 延遲三秒時仍能讀普通 graph。跨兩個真 Akka node 可往返完整 1MiB、含 JSON 跳脫字元的 value。
